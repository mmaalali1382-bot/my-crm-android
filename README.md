# CRM شخصی اندروید — نسخه آغازین

این مخزن، اسکلت اولیه رابط کاربری CRM است و هنوز نسخه نهایی یا APK نصب‌شدنی نیست.

## امکانات فعلی
- رابط فارسی و راست‌چین با تم سرمه‌ای و سفید
- داشبورد اولیه
- فهرست مشتریان و افزودن مشتری در حافظه موقت صفحه
- بخش‌های نمایشی محصولات و سفارش‌ها
- طرح اولیه جداول SQLite در `src/db/schema.ts`

## مواردی که هنوز باید پیاده‌سازی و آزمایش شوند
- اتصال واقعی SQLite و ماندگاری داده پس از بستن برنامه
- فرم‌ها و گردش کامل سفارش، موجودی، پرداخت و گزارش مالی
- تاریخ شمسی، پشتیبان‌گیری و همگام‌سازی
- دستیار صوتی/تایپی و قابلیت‌های هوش مصنوعی
- ساخت و آزمایش APK روی گوشی اندرویدی

## اجرای توسعه
نیازمند Node.js است:
1. `npm install`
2. `npm run build`

برای تبدیل به پروژه اندروید، پس از آماده شدن محیط توسعه:
`npx cap add android` و سپس `npx cap sync android`

هیچ سرویس پولی یا کلید API در این نسخه تنظیم نشده است.
